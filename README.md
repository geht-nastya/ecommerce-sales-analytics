# ecommerce-sales-analytics

## О проекте
Проект посвящён анализу продаж интернет-магазина на основе транзакционных данных. Цель — изучить динамику выручки, поведение клиентов, популярные товары и различия между рынками с помощью SQL.

## Бизнес-задачи
* Рассчитать ключевые показатели продаж.
* Изучить месячную динамику выручки и количества заказов.
* Определить товары с наибольшей выручкой.
* Сравнить результаты по странам.
* Оценить долю клиентов с повторными покупками.
* Проверить качество данных и учесть отмены и возвраты.

## Данные

**Источник:** UCI Machine Learning Repository — Online Retail.

Исходный набор содержит 541 909 транзакционных строк за период с 1 декабря 2010 года по 9 декабря 2011 года.

Основные поля: номер счёта, код товара, описание, количество, дата транзакции, цена за единицу, идентификатор клиента и страна.

## Инструменты
* SQL — очистка, преобразование, агрегация и анализ данных.
* DuckDB — выполнение SQL-запросов.
* Google Colab — среда для запуска запросов и представления результатов.

Python используется как оболочка для выполнения SQL и отображения таблиц.

## Ключевые результаты
* **Выручка положительных продаж:** £10,666,684.54.
* **Количество заказов:** 19,960.
* **Средний чек:** £534.40.
* **Идентифицированные клиенты:** 4,338.
* **Клиенты с двумя или более заказами:** 2,845 (65.58%).

## Основные выводы
1. Ноябрь 2011 года стал наиболее сильным месяцем в анализируемом периоде: выручка составила около £1.51 млн, увеличившись на 30.7% относительно октября.
2. Великобритания является крупнейшим рынком по выручке — около £9.03 млн.
3. В Нидерландах и Австралии средний чек существенно превышает медианный, что указывает на влияние крупных заказов.
4. Среди идентифицированных клиентов 65.58% совершили два или более заказа за период наблюдения.
5. При анализе ассортимента необходимо отдельно рассматривать почтовые услуги, ручные позиции и потенциальные аномалии количества.

## Методология и ограничения
Для анализа положительных продаж были исключены счета, начинающиеся с `C`, строки с неположительным количеством и строки с неположительной ценой. Исходные данные сохранены отдельно.

Рассчитанная выручка отражает отобранные положительные продажи и не является чистой выручкой после вычета возвратов.

Идентификаторы клиентов отсутствуют у части транзакций, поэтому клиентские показатели рассчитаны только для строк с известным `CustomerID`. Доля повторных клиентов относится к периоду наблюдения и не является показателем удержания на фиксированном горизонте.

Декабрь 2011 года представлен не полностью — данные заканчиваются 9 декабря. Выручка используется как показатель продаж; прибыль не рассчитывалась, поскольку себестоимость товаров отсутствует.
